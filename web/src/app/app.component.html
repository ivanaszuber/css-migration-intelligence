What does “value conflict” mean?

Different values across clients are expected. A conflict means one proposed property has two or more values inside the same client. Replacing those with one token could alter its design, so that proposal is not preselected. Expand its client values below to see exactly where the conflict is.

What is residual CSS?

It is CSS left unchanged in the generated migration copy. Some rules are valid but not in the approved property contract; others control layout, refer to assets, or need safety review. Nothing here is automatically a customer problem. Use the queue above to record a proposed action, then validate it with the module owner and customer where appropriate.

Important distinction

This is a configuration proposal, not a production migration

Generated tenant CSS still contains original structural rules. The demo identifies candidates and makes approved values editable; a production UI-kit change and customer sign-off are separate gates.
